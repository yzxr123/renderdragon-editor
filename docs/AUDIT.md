# 开源整理与审计记录

日期：2026-11-22。范围：用户提供的整个网站目录，包括内嵌画板、默认数据和压缩模板。原目录只读，修改在独立交付副本完成。

## 来源和名称

- 已检查所有 18 个原始网站文件，并解开画板文档与 gzip/TAR 模板。
- 模板包含 2,536 张 PNG、167 张 TGA，共 2,703 张。提交者明确确认均可按 MIT 开源，因此全部保留，逐字节抽出为源文件。
- 在已扫描文本和解压文件名中未发现“双小”“双晓”“小时代”或工作室宣传标识。不能据关键词扫描断言所有未知名称均无第三方含义。
- 保留 JS Paint、Piskel、skinview3d 的原代码来源线索，并补充可确认的 MIT 许可文本，不将移除来源说明作为“原创化”。
- 文件采用 kebab-case；模块使用 core、registry、workspace，画板状态使用 paintState，schema 构造器使用 numberField、colorField 等语义名称。界面内部 studio 命名统一为 inspector/editor。数学短变量和引擎协议键保留惯用命名。
- 主页面标题和版本统一为 1.0.0，修正“基水雾修改项”等含糊文案与“当前群系导出”范围描述。

## 已修复

| 问题 | 修改 |
| --- | --- |
| 目标选择使用原型链属性判断，constructor 等名字被接受 | 只接受 TARGETS 的自有属性 |
| MERS 零尺寸图层会产生无效采样 | 验证每个源图层的尺寸和数据长度 |
| 算法输入与参数缺少校验 | 检查图像数据、有限数值和已知配置字段，限制输出像素数 |
| 参数配方缓存为非数组时破坏状态读取 | 校验缓存形状，忽略无效条目 |
| 事务失败没有恢复目录索引 | 一并回滚 directories 和 children，防止残留虚假目录 |
| 巨型转义字符串难维护 | 拆出画板源码与全部贴图，使用标准库脚本重新生成 |
| 大量未调用函数与冗余注释 | 删除 44 个无调用方函数，清除过时/装饰性注释及 CSS 分段注释，保留关键算法、兼容性和许可说明 |

## 验证

- Node 核心回归：7 项，覆盖非法目标、无效尺寸、非有限参数、PNG CRC 与 MERS 通道往返、FIO 往返、JSON 字段路径及确定性 PBR 生成。
- Edge/Chromium 浏览器：启动、87 个群系、画板、全部分类、事务回滚、未改动时空导出、修改编译、manifest UUID、参数修改项往返、原包只读、坏缓存、主题、配色与窄视口。
- 参数修改导出样例为 3 个文件，修改项含 2 个参数/群系条目，没有整包贴图混入。
- 最终语法检查、重建一致性、原模板贴图 SHA-256 对照及部署状态以本次执行结果为准。

## 已知边界

本轮验证的是浏览器编辑器与导出逻辑，未进行 Minecraft/网易游戏运行验证，也不是逐张素材独立版权鉴定。界面和 JSON 的历史兼容 API 未整体重写。布局窄视口检查只验证核心面板可见，不代表完成所有移动设备体验验收。
